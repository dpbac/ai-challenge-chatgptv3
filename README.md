# AI Personal Challenge Topic Selector

This Streamlit application helps students choose topics for their AI Personal Challenge projects through an interactive quiz and personalized recommendations.

## Features

- Interactive quiz to assess student interests and background
- Personalized topic recommendations based on quiz answers
- Ready-to-use AI conversation prompts for each topic
- Project plan template and download functionality

## Installation

1. Clone this repository
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

To run the application, use the following command:
```bash
streamlit run app.py
```

The application will open in your default web browser.

## Usage

1. Start by taking the quiz to assess your interests and background
2. Review the top 3 topic recommendations
3. Select a topic to explore further
4. Use the provided AI conversation prompt to discuss your chosen topic
5. Fill out the project plan template (TO DO)
6. Download your completed project plan (TO DO)
